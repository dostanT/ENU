Корень проекта

CLAUDE.md - правила работы над проектом: стиль объяснений (ELI5), структура папок, форматирование файлов, что код на Java нужно реально компилировать и запускать (JDK 25 есть в окружении), как вести MAP.md. syllabus-toc.md - разбор силлабуса по неделям: полный список тем модуль 1 (недели 1-7, основы ООП до функциональных интерфейсов) и модуль 2 (недели 8-15, строки/исключения/коллекции/потоки/JDBC/сети/XML), с примерными диапазонами страниц в PDF. Отмечает, что силлабус - не просто список тем, а содержит краткие конспекты лекций и банк вариантов лабораторных (Option A/B/C) по всем 15 неделям. Список литературы, на которую силлабус ссылается чаще всего (Eckel, Horstmann, Oracle Docs).

lectures

01-vvedenie-v-oop-i-istoriya-java.md - конспект по теме 1 (Введение в ООП, краткая история Java, основы классов и объектов). История Java (Green Project → Oak → Java, WORA), механизм javac→байткод→JVM и разница JDK/JRE/JVM, структура программы (class/main/statements) с реально собранным и запущенным Hello World. Классы и объекты на примерах Car и Student (оба реально скомпилированы и запущены, включая изменение состояния объекта через increaseGpa). Три принципа ООП: инкапсуляция (BankAccount, проверено), наследование+полиморфизм вместе (Animal/Dog/Cat, проверено - показано, что вызов метода зависит от реального типа объекта, а не типа переменной). Java как мультипарадигменный язык - ООП/императивный стиль против функционального (FP): лямбды и Stream API, реально скомпилировано и запущено (map/toList/sum). Console I/O через Scanner, тоже реально запущено с поданным вводом. Коротко про IDE и структуру проекта (без кода - не подлежит проверке). За рамками конспекта - 6+3 практических задачи из презентации (самостоятельная работа, не часть конспекта); решены отдельно, см. solutions/Lecture 1 - Practice for Students (slides 30-32).md.

solutions

Lecture 1 - Practice for Students (slides 30-32).md - решение всех 9 практических задач со слайдов 30-32 лекции 1 (задачи "Practice for Students (in class)"): слайд 30 - сумма первых N целых, сумма ряда дробей 1+1/2+...+1/N, знакочередующийся ряд; слайд 31 - круг (площадь и длина окружности), прямоугольный треугольник по катетам, расстояние между двумя точками; слайд 32 - сдвиг, масштабирование и поворот треугольника. Девять отдельных программ (SumOfIntegers, SumOfFractions, AlternatingSeries, CircleCalculator, RightTriangleCalculator, PointDistance, TriangleTranslation, TriangleScaling, TriangleRotation) с Scanner/System.out, реально скомпилированы (javac 25, -Xlint:all без предупреждений, также --release 8) и запущены 46 раз на примерах со слайдов и своих значениях, каждый результат сверен с независимым расчётом на Python. К каждой задаче - объяснение через "копилку" (накопитель), ручной пример до кода и реальный вывод. Разобраны настоящими запусками типичные ловушки: целочисленное деление (1/k даёт 0), переполнение int при сумме 1..N, ^ - это XOR а не степень, градусы вместо радиан в Math.sin/cos, "-0.00" от вычислительного шума, локаль (на ru_RU/kk_KZ/ru_KZ без Locale.setDefault(Locale.US) Scanner не принимает "2.5", а вывод идёт с запятой; на Mac пользователя локаль en_KZ, там точка работает).

Lecture 2 - Analysis of an Integer Array (slides 38-42).md - решение классной работы "Analysis of an Integer Array" из конца Lecture 2 (слайды 38-42): разбор готовой программы со слайда 40 (максимум, минимум, сумма, среднее, счётчики положительных/отрицательных/нулей за один проход по int[]) с ручной трассировкой, затем все пункты "Task for Students": запуск данного кода, другой массив, ввод с клавиатуры (с защитой от n < 1 и от не-чисел), счётчик "больше заданного значения", меню на switch (максимум/минимум/среднее/счётчики/выход) и оба Extra (чётные числа, сумма положительных). Все программы реально скомпилированы (javac 25 -Xlint:all, также --release 8) и запущены (ввод через псевдотерминал), результаты сверены с расчётом на Python. Проверены запуском ловушки: целочисленное деление, ArrayIndexOutOfBoundsException на пустом массиве, -5 % 2 == -1, повторное имя переменной в case.
