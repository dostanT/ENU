# Силлабус курса — ООП на Java (OOPJ 3215)

Справочник по `syllabus/Объектно ориентированное программирование Java.pdf`
(ЕНУ, "Educational and Methodological Complex of the Discipline", 3rd/7th
edition разделы смешаны в одном файле, ~64 страницы). Номера страниц —
это номера страниц самого PDF (в файле нет отдельной печатной нумерации,
поэтому смещения искать не нужно — открывай PDF-страницу как есть). Границы
разделов приблизительные (±1-2 страницы).

Важно: этот силлабус — не просто список тем. Он уже содержит:
- краткий конспект лекции на английском для каждой из 15 недель (план,
  объяснение, примеры кода, вопросы на самопроверку, рекомендованные
  источники) — стр. ~15-45;
- банк вариантов лабораторных работ (Option A/B/C, конкретные задания) для
  каждой из 15 лаб — стр. ~46-60;
- задания на самостоятельную работу (СРО) — стр. ~61;
- список литературы — стр. ~10, 62;
- вопросы к рубежным контролям и итоговому экзамену — стр. ~63-64.

## Модуль 1. Introduction to Java Programming (недели 1-7)

1. Введение в ООП. Краткая история Java. Основы классов и объектов.
   Версии Java-машины и их эволюция — стр. ~15-16
2. Типы данных и операторы. Условный оператор. Оператор выбора. Циклы.
   Массивы — стр. ~16-17
3. Классы и методы. Переменные класса, переменные экземпляра, константы.
   Ограничения доступа. Конструкторы. Проектирование методов — стр. ~17-18
4. Наследование и полиморфизм. Переопределение методов и полиморфизм —
   стр. ~18-20
5. Внутренние классы. Вложенные классы. Анонимные классы — стр. ~20-22
6. Интерфейсы и аннотации. Параметризация интерфейсов. Аннотации —
   стр. ~22-24
7. Функциональные интерфейсы. Predicate. Consumer. Comparator —
   стр. ~24-26

## Модуль 2. Java Language Classes and Packages (недели 8-15)

8. Строки. Класс String. StringBuilder и StringBuffer. Регулярные
   выражения. Интернационализация приложения, чисел и дат. Date/Time API —
   стр. ~26-28
9. Исключения и ошибки. Иерархия исключений. Способы обработки. Обработка
   нескольких исключений. Оператор throw — стр. ~28-30
10. Потоки ввода-вывода. Байтовые и символьные потоки. Чтение из потока.
    Класс Scanner — стр. ~30-32
11. Коллекции и STREAM API. Иерархия коллекций. ArrayList. LinkedList и
    интерфейс Queue. Deque и ArrayDeque. STREAM API. Лямбда-выражения —
    стр. ~32-34
12. Потоки выполнения (Thread). Класс Thread и интерфейс Runnable.
    Жизненный цикл потока. Управление и завершение потоков. Синхронизация,
    synchronized — стр. ~34-37
13. Java DataBase Connectivity. Драйверы, соединения, запросы. Шаблон
    Data Access Object (DAO) — стр. ~37-39
14. Сетевые программы. Сокеты по TCP/IP. Многопоточность в сети. Сервлеты
    — стр. ~39-41
15. Java API для обработки XML. Модель DOM. Сериализация и десериализация.
    Создание XML-документа — стр. ~41-45

## Лабораторные работы

Лабы пронумерованы 1-15 и соответствуют темам лекций 1-15 один в один
(лаба 1 — тема недели 1, и так далее). У каждой лабы есть варианты
(Option A / Option B / иногда Option C) с конкретными пронумерованными
заданиями внутри — если пользователь просит помочь с "лабой N" без
уточнения варианта, спроси или загляни, какие есть варианты, на
странице этой лабы в PDF, прежде чем решать.

## Литература, на которую чаще всего ссылается силлабус

После КАЖДОЙ из 15 лекций в силлабусе повторяется один и тот же короткий
список "Recommended sources" — это де-факто основные три источника курса:
- Eckel, B. — "Philosophy of Java" (он же "Thinking in Java")
- Horstmann, K. S. — "Java. Professional Library" (Fundamentals + Extended
  programming tools, 2 тома)
- Oracle Java Documentation (https://docs.oracle.com/en/java/)

Более широкий список из титульной части силлабуса (стр. ~10, ~62) включает
дополнительно: Deitel & Deitel "Java How to Program", Bloch "Effective
Java", Sierra & Bates "Head First Java", Schildt "A Beginner's Guide",
Gradi Butch "Object-oriented analysis and design", Fowler "Refactoring" —
если пользователь принесёт один из этих учебников как книгу курса, это
ожидаемо, не только Eckel/Horstmann.
