# FitnessCRM (Java + Spring Boot) — план до 24.12.2026

Версия: черновик 1 от 05.10.2026. Это живой документ: каждую неделю он обновляется по новым лабам, лекциям и заданиям. Он заменяет прежний план для Swift и Supabase (тот лежит в архиве `C:\ENU\FitnessCRM\FitnessCRM\PLAN`, его не трогаем).

## Что мы делаем

FitnessCRM — веб-приложение на Java и Spring Boot для сотрудников сети фитнес-клубов «FitLife» (3 филиала, 120 сотрудников, 40 рабочих мест — это компания из твоих лабораторных ИСРП). Страницы рисует Thymeleaf (HTML собирается на сервере), данные лежат в Microsoft SQL Server, вход и роли даёт Spring Security. Проект показывается сразу на трёх предметах:
- «Инструментальные средства разработки программ» (ИСРП): моделирование, документы, диаграммы;
- «Объектно-реляционные СУБД» (БД): схема, T-SQL, транзакции, индексы, представления;
- «ООП на Java»: классы, наследование, интерфейсы, исключения, коллекции, потоки, JDBC.

Как читать термины: FitLife — сеть клубов (заказчик из лаб ИСРП), FitnessCRM — программа, которую мы для неё делаем, сотрудники клуба — пользователи, ты — исполнитель.

## Допущения (я так понял, но ты этого прямо не говорил — поправь, если не так)

- Git — один общий репозиторий в корне `C:\ENU` (он уже подключён к GitHub). Отдельный `git init` в `FitnessCRMJava` не делаем: вложенный репозиторий внешний git не видит, и файлы проекта в коммит не попадут. Пароль к базе в репозиторий не попадает.

- БД: скрипт лежит в `db/`, ограничения и права написаны и проверены тестовым скриптом, тестовые данные (seed) есть.
- Java: сущность, репозиторий, сервис, контроллер и страница; есть состояния «пусто» и «ошибка»; исключения не глотаются.
- Сценарий недели проходит вручную от начала до конца.
- ИСРП-артефакт (диаграмма или текст) обновлён.
- Сделан git-коммит с понятным сообщением.

Как я проверяю твою работу (честно про границы):
- SQL: запускаю в временной базе SQL Server через `sqlcmd` (Windows-аутентификация). Твою рабочую базу `FitnessCRM` только читаю, не пишу; временную базу удаляю.
- Java: читаю код и собираю копию проекта через `mvnw.cmd` (твои файлы и IntelliJ не трогаю). Могу прогнать тесты. Запуск приложения на твоей базе — всегда за тобой. Страницы глазами я не вижу: внешний вид проверяешь ты.
