Лабораторная работа №2 - Двоично-десятичный код (вариант 1)

Задание

Закодировать и декодировать заданные числа двоично-десятичным кодом (ДДК, BCD) с разными наборами весов тетрад.

Теоретическая часть

Двоично-десятичный код - способ записи десятичного числа, при котором каждая отдельная десятичная цифра (0-9) превращается в свою группу из 4 бит (тетраду), а не всё число целиком переводится в двоичную систему одним куском.

4 бита дают 2^4 = 16 комбинаций, а десятичных цифр всего 10 (0-9) - из 16 возможных комбинаций тетрады используется только 10, 6 остаются запрещёнными. В обычном двоичном числе бит на позиции i весит 2^i, но ДДК может использовать любой набор из 4 весов, лишь бы их суммированием (для разных сочетаний нулей и единиц) получались все числа от 0 до 9 без повторов - отсюда варианты 8-4-2-1, 5-2-1-1, 6-3-2-1 и т.д.

Кодирование цифры набором весов (q1, q2, q3, q4), где q1 - вес первого (старшего) бита тетрады: берётся вес очередного бита слева направо; если он меньше или равен тому, что осталось от цифры (остаток изначально равен самой цифре) - в этот бит пишется 1 и вес вычитается из остатка; если вес больше остатка - пишется 0; переход к следующему биту с новым весом.

Декодирование - обратная операция: для каждого бита тетрады, равного 1, складываются соответствующие веса, сумма и есть исходная цифра.

Задание 1. Закодировать число 8701 кодом 5-2-1-1

Веса по порядку битов: 5, 2, 1, 1.

Цифра 8, остаток 8:
вес 5: 5 <= 8 -> бит 1, остаток 8-5=3
вес 2: 2 <= 3 -> бит 1, остаток 3-2=1
вес 1: 1 <= 1 -> бит 1, остаток 1-1=0
вес 1: 1 <= 0? нет -> бит 0
Тетрада для 8: 1110. Проверка: 5+2+1+0=8.

Цифра 7, остаток 7:
вес 5: 5<=7 -> бит 1, остаток 2
вес 2: 2<=2 -> бит 1, остаток 0
вес 1: 1<=0? нет -> бит 0
вес 1: 1<=0? нет -> бит 0
Тетрада для 7: 1100. Проверка: 5+2+0+0=7.

Цифра 0, остаток 0: все веса больше остатка -> все биты 0.
Тетрада для 0: 0000.

Цифра 1, остаток 1:
вес 5: 5<=1? нет -> бит 0
вес 2: 2<=1? нет -> бит 0
вес 1: 1<=1 -> бит 1, остаток 0
вес 1: 1<=0? нет -> бит 0
Тетрада для 1: 0010. Проверка: 0+0+1+0=1.

Ответ: 8701 в коде 5-2-1-1 записывается как 1110 1100 0000 0010.

Задание 2. Декодировать 001001011100, код 6-3-2-1

Веса по порядку битов: 6, 3, 2, 1. Разбивка на тетрады: 0010 0101 1100.

Тетрада 0010: 0*6 + 0*3 + 1*2 + 0*1 = 2 - первая цифра.
Тетрада 0101: 0*6 + 1*3 + 0*2 + 1*1 = 4 - вторая цифра.
Тетрада 1100: 1*6 + 1*3 + 0*2 + 0*1 = 9 - третья цифра.

Ответ: 249.

Задание 3. Декодировать 100101110010, код 8-4-2-1

Это стандартный BCD, веса совпадают с обычными двоичными разрядами: 8, 4, 2, 1. Разбивка на тетрады: 1001 0111 0010.

Тетрада 1001: 1*8+0*4+0*2+1*1 = 9.
Тетрада 0111: 0*8+1*4+1*2+1*1 = 7.
Тетрада 0010: 0*8+0*4+1*2+0*1 = 2.

Ответ: 972.

Проверка результата

Для проверки написана программа на Python с той же логикой (кодирование - вычитание веса из остатка, декодирование - сумма весов на позициях с единицей):

```python
def encode_digit(digit, weights):
    bits = []
    remainder = digit
    for w in weights:
        if w <= remainder:
            bits.append(1)
            remainder -= w
        else:
            bits.append(0)
    return bits

def decode_tetrad(bits, weights):
    return sum(b * w for b, w in zip(bits, weights))

# Задание 1: закодировать 8701 весами 5-2-1-1
w1 = [5, 2, 1, 1]
for digit in "8701":
    bits = encode_digit(int(digit), w1)
    print(f"encode({digit}, 5-2-1-1) = {''.join(map(str, bits))}")

# Задание 2: декодировать 001001011100 весами 6-3-2-1
w2 = [6, 3, 2, 1]
code2 = "001001011100"
tetrads2 = [code2[i:i+4] for i in range(0, len(code2), 4)]
result2 = "".join(str(decode_tetrad([int(c) for c in t], w2)) for t in tetrads2)
print(f"decode({code2}, 6-3-2-1) = {result2}")

# Задание 3: декодировать 100101110010 весами 8-4-2-1
w3 = [8, 4, 2, 1]
code3 = "100101110010"
tetrads3 = [code3[i:i+4] for i in range(0, len(code3), 4)]
result3 = "".join(str(decode_tetrad([int(c) for c in t], w3)) for t in tetrads3)
print(f"decode({code3}, 8-4-2-1) = {result3}")
```

Вывод программы:

encode(0, 5-2-1-1) = 0000

decode(001001011100, 6-3-2-1) = 249

Ответы на контрольные вопросы

1) Что такое двоично-десятичный код?
Это способ представления десятичного числа, при котором каждая отдельная десятичная цифра (0-9) кодируется своей отдельной группой из 4 битов (тетрадой), а не число целиком переводится в двоичную систему. Из 16 возможных комбинаций тетрады используются только 10 (по числу десятичных цифр), а 6 остаются избыточными, неиспользуемыми.

2) При каких условиях строятся ДДК?
Веса тетрады q1 (для младшего бита), q2, q3, q4 выбираются не произвольно, а так, чтобы суммами разных подмножеств этих весов можно было ровно и однозначно получить все числа от 0 до 9. Правила, по которым строится большинство используемых кодов:
- вес младшего разряда q1 = 1;
- вес второго разряда q2 = 1 или 2;
- веса двух оставшихся (старших) разрядов подбираются так, чтобы их сумма была не меньше 6 (если q2=2) или не меньше 7 (если q2=1).
Соблюдение этих условий даёт 17 практически используемых вариантов кодов (8-4-2-1, 7-4-2-1, 6-4-2-1, 5-4-2-1 и т.д.), из которых 8-4-2-1 - единственный, где представление каждой цифры однозначно (в остальных одно и то же число иногда можно записать двумя разными тетрадами).

3) Где могут применяться ДДК?
Там, где нужно точно работать с десятичными цифрами, но обрабатывать их электроникой, которая оперирует битами: цифровые часы и калькуляторы, цифровые вольтметры и другие измерительные приборы с цифровой индикацией, финансовые и бухгалтерские расчёты (где обычная двоичная арифметика с плавающей точкой даёт неточности при округлении десятичных сумм), устройства ввода-вывода десятичных данных (клавиатуры, дисплеи). Обратная сторона - ДДК менее компактен и медленнее в арифметике, чем обычный двоичный код, поэтому внутри процессора числа почти всегда хранят в чистом двоичном виде, а в BCD переводят только на границе с человеком (ввод/вывод).
