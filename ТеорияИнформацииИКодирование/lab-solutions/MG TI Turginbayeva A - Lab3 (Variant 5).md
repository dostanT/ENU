Лабораторная работа №3 - Код Грея (вариант 5)

Вариант работы

Порядковый номер по списку группы - 10. В лабораторной 5 вариантов, номер варианта вычисляется по формуле (N-1) mod 5 + 1, где N - номер по списку: (10-1) mod 5 + 1 = 9 mod 5 + 1 = 4 + 1 = 5. Выполняется вариант 5.

Задание

Код Грея - способ записывать числа в двоичном виде так, чтобы у любых двух соседних чисел код отличался ровно в одном разряде, а не в нескольких сразу (обычная двоичная запись этим свойством не обладает). Нужно перевести заданное двоичное число в код Грея (кодирование) и заданный код Грея - обратно в двоичное число (декодирование).

Теоретическая часть

Возьмём обычный 3-битный счётчик от 0 до 7 в привычной двоичной записи: 000, 001, 010, 011, 100, 101, 110, 111. От 001 к 010 (от 1 к 2) меняются сразу два бита. От 011 к 100 (от 3 к 4) меняются сразу все три бита.

Это значимо для физических датчиков (например энкодера угла поворота - диска с несколькими дорожками, каждая дорожка кодирует один бит числа). Дорожки не могут переключиться абсолютно синхронно, всегда есть небольшая задержка между ними. Если при переходе 011->100 три бита переключаются не одновременно, датчик на мгновение может зафиксировать мусорное промежуточное значение, которого вообще не должно было быть между этими двумя углами - например 001 или 110 вместо ожидаемых 011 или 100. В критичной системе (авиация, станки с ЧПУ) такая ложная точка может быть опасна.

Тот же счёт от 0 до 7 в коде Грея: 000, 001, 011, 010, 110, 111, 101, 100. На каждом шаге меняется ровно один разряд, в том числе по кругу - от последнего 100 к первому 000 тоже меняется только один бит. Раз соседних чисел с двумя одновременно меняющимися битами нет, мусорному промежуточному значению взяться неоткуда: какой бы бит ни "запоздал", считанное значение в худшем случае окажется либо старым, либо новым соседним, но не третьим, случайным.

Формула кодирования (обычное двоичное число -> код Грея):

Y_n = X_n
Y_i = X_i xor X_(i+1), для i = 1, 2, ..., n-1

X - исходное двоичное число, Y - код Грея, n - число бит, i - номер разряда (i=1 - младший, самый правый бит; i=n - старший, самый левый), xor - исключающее ИЛИ (сложение по модулю 2): результат 1, если сравниваемые биты разные, и 0, если одинаковые. Старший бит переписывается без изменений, каждый следующий бит кода Грея - xor соответствующего бита исходного числа с его более старшим соседом.

Проверка формулы на числе X = 011 (это 3, n=3): Y3=X3=0; Y2=X2 xor X3=1 xor 0=1; Y1=X1 xor X2=1 xor 1=0. Результат 010 - совпадает со значением на месте числа 3 в таблице кода Грея выше.

Формула декодирования (код Грея -> обычное двоичное число):

X_n = Y_n
X_i = X_(i+1) xor Y_i, для i = n-1, n-2, ..., 1 (от старшего разряда к младшему)

Старший бит переписывается без изменений, каждый следующий бит X - xor уже вычисленного соседнего (более старшего) бита X с соответствующим битом Y.

Проверка результата

Программа на Python с той же формулой, дополнительно сверенная на обоих готовых примерах из методички (кодирование 10111101011 -> 11100011110 и декодирование 1110101 -> 1011001):

```python
def bin_to_gray(bits):
    n = len(bits)
    X = [int(b) for b in bits]
    Y = [0]*n
    Y[0] = X[0]
    for k in range(1, n):
        Y[k] = X[k] ^ X[k-1]
    return ''.join(str(b) for b in Y)

def gray_to_bin(bits):
    n = len(bits)
    Y = [int(b) for b in bits]
    X = [0]*n
    X[0] = Y[0]
    for k in range(1, n):
        X[k] = X[k-1] ^ Y[k]
    return ''.join(str(b) for b in X)

assert bin_to_gray("10111101011") == "11100011110"
assert gray_to_bin("1110101") == "1011001"

print(bin_to_gray("110011001"))
print(gray_to_bin("10001111001"))
```

Ответы на контрольные вопросы

Какие особенности у кода Грея? - у любых двух соседних чисел (по порядку счёта) код отличается ровно в одном разряде, никогда в нескольких сразу. Это называют отражённым (рефлексным) кодом - кодовое расстояние между соседними комбинациями равно единице. Обычная двоичная запись этим свойством не обладает: например переход 3->4 (011->100 в обычном двоичном) меняет сразу все три бита.

Где применяется код Грея? - там, где считывается физическая, механически или оптически меняющаяся величина и важно не поймать мусорное промежуточное значение при переходе между соседними отсчётами: датчики угла поворота (энкодеры), АЦП (аналого-цифровые преобразователи), карты Карно в цифровой схемотехнике (соседние клетки карты отличаются на 1 бит специально по этой же причине), иногда в передаче данных для снижения числа ошибок на границах соседних значений.

Как обычный двоичный код переводится в код Грея? - старший бит кода Грея равен старшему биту исходного числа без изменений (Y_n = X_n). Каждый следующий, более младший бит кода Грея получается операцией исключающее ИЛИ (xor, сложение по модулю 2) между этим же битом исходного числа и его более старшим соседом (Y_i = X_i xor X_(i+1)). Обратное декодирование делается тем же xor, только накопительно сверху вниз: старший бит переписывается как есть, а каждый следующий бит двоичного числа - xor уже восстановленного соседнего старшего бита с соответствующим битом кода Грея (X_i = X_(i+1) xor Y_i).
