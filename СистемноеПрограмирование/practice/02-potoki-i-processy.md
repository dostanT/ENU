Задания для самопроверки - Глава 2. Потоки и процессы

Охватывает весь объём lectures/02-potoki-i-processy.md (книга Побегайло, стр. 29-40: 2.1-2.5). Только формулировки, без ответов - если захочешь проверить решения, попроси, разбор появится в practice-solutions/02-potoki-i-processy.md.

Определение потока

1. Программа читает три числа a, b, c и печатает их в порядке возрастания (сортирует три числа). Сколько РАЗНЫХ потоков управления (в смысле главы 2 - конкретных пройденных последовательностей инструкций, не текста кода) может породить эта программа в зависимости от входных данных? Перечисли их.

2. main вызывает функцию compute(x) и печатает результат сразу после вызова, не делая ничего между вызовом и печатью. Это один поток или два? А если бы main запустила compute(x) в фоне (не дожидаясь ответа) и продолжила делать что-то своё, а результат забрала позже? Объясни разницу.

Контекст потока: реентерабельность и потокобезопасность

3. Дана функция:
```
int cache;
int square_cached(int n)
{
    cache = n * n;
    return cache;
}
```
Реентерабельна ли она? Потокобезопасна? Что произойдёт, если два потока вызовут её параллельно с разными n?

4. Дана функция:
```
int next_id()
{
    static int id = 0;
    return ++id;
}
```
Ответь на те же три вопроса, что в задании 3, и объясни разницу между этим случаем и функцией с обычной (не static) локальной переменной.

5. Своими словами объясни, почему реентерабельная функция автоматически безопасна для потоков, а потокобезопасная функция не обязательно реентерабельна. Может ли функция быть одновременно нереентерабельной и небезопасной? Приведи пример.

Состояния потока

6. Если бы система поддерживала только базовые переходы (Create/Exit/Run/Interrupt/Block/Unblock), без Suspend/Resume и без Sleep/Wakeup, сколько состояний потребовалось бы в модели? Перечисли их.

7. Объясни разницу между операциями Block и Suspend - обе как будто "останавливают" поток, но по разным причинам и разными участниками. Кто инициирует каждую из них?

8. К модели без Suspend/Resume добавили только Sleep/Wakeup (но не Suspend/Resume). Сколько состояний в такой модели? А если добавить и то, и другое сразу?

Диспетчеризация и планирование

9. В системе три уровня приоритета потоков (высокий/средний/низкий), в каждом очередь FCFS. Опиши по шагам, в каком порядке процессор достанется пяти потокам, если два из них имеют высокий приоритет, два - средний и один - низкий, и все они появились в системе одновременно.

10. Объясни разницу между планированием и диспетчеризацией - это разные задачи управления потоками, хотя термины похожи по звучанию.

11. Почему нельзя просто сделать квант времени бесконечно маленьким, чтобы система реагировала на всё мгновенно? Какую цену пришлось бы за это заплатить?

Определение процесса

12. Два потока одного процесса хотят обменяться числом через общую переменную. Два процесса (без общих потоков) хотят сделать то же самое. Почему для потоков это можно сделать "бесплатно" (просто прочитать/записать переменную), а для процессов нужны специальные, более дорогие механизмы? Свяжи ответ с понятием адресного пространства.
