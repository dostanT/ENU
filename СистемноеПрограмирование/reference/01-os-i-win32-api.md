Справочник. Глава 1. ОС и Win32 API

Только суть: логика и синтаксис, без объяснений с нуля (объяснения - в lectures/01-os-i-win32-api.md).

Логика

- ОС = менеджер ресурсов компьютера. Две задачи: управлять ресурсами и распределять (планировать) их между программами.
- Классификация ОС: по числу программ (однопрограммная / мультипрограммная), по числу процессоров (одно- / мультипроцессорная), по типу задач (обычная / реального времени - последняя управляет объектом без человека, цена задержки - авария).
- Win32 API - набор функций Windows (не лезем в железо напрямую). Категории: Base Services, Common Control Library, GDI, Network Services, User Interface, Windows NT Access Control, Windows Shell, Windows System Information. Курс = Base Services + Windows NT Access Control. Поэтому все примеры консольные.
- Объект = структура данных, представляющая системный ресурс (процесс, поток, файл, канал). Три категории: User (окна, курсоры), GDI (кисти, перья), Kernel (процессы, потоки, файлы). Курс = только Kernel.
- К объекту нет прямого доступа. Доступ только через дескриптор (тип HANDLE). Дескриптор = запись в таблице ОС: адрес объекта + тип объекта.
- Дескрипторы создаёт ОС, возвращают функции вида CreateXxx (CreateProcess, CreateThread, CreateFile...). Успех: результат не NULL и не отрицательный.
- Закончил работу - CloseHandle. Она закрывает дескриптор, а не обязательно объект: объект живёт, пока есть хотя бы один дескриптор на него (подсчёт ссылок; дескрипторов может быть несколько - дублирование, наследование).

Типы данных Win32 (псевдонимы C через typedef, заглавными)

- CHAR = char, UCHAR/BYTE = unsigned char, SHORT = short, USHORT/WORD = unsigned short
- INT = int, BOOL = int (FALSE = 0, TRUE = 1, через #define), UINT = unsigned int
- LONG = long, ULONG/DWORD = unsigned long, FLOAT = float
- LPVOID = void*, LPCVOID = const void*
- Приставки: P и LP = указатель на (LP - "long pointer", наследие 16 бит, в Win32 разницы нет); C внутри имени = const (LPCVOID). Пример: LPDWORD = DWORD*, PBYTE = BYTE*.

Функции

CloseHandle
BOOL CloseHandle(HANDLE hObject);
- hObject - дескриптор любого объекта ядра, который закрываем
- возврат: не 0 - успех, FALSE (0) - ошибка
- ловушка: не уничтожает объект, пока остаются другие дескрипторы на него
