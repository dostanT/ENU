# Оглавление книги — Побегайло, «Системное программирование в Windows»

Справочник для быстрой навигации по `Pobegailo Windows.pdf` (1056 стр.).
Составлен по реальному оглавлению книги (стр. 3–13 PDF). Номера страниц
ниже — это **напечатанные в книге номера**, не номера страниц PDF-файла.

## Смещение страниц (важно)

**Страница PDF = напечатанная страница + 1** (в начале книги 1 непронумерованная
страница перед стр. 1). Проверено на нескольких точках оглавления —
смещение постоянное. Пример: глава 4 напечатана на стр. 58 → открывать
PDF-страницу 59. Перед тем как писать конспект по новой для тебя части
книги — открой первую страницу диапазона и убедись, что заголовок
совпадает с ожидаемой темой; если нет — скорректируй смещение и
запомни его для этой части книги.

Не более 20 страниц за один вызов чтения PDF — большие главы читай
несколькими диапазонами подряд.
