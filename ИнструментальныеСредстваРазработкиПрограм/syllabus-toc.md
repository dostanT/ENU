# Навигация по силлабусу — TPD 3301 Tools of program development

Справочник по файлу `syllabus/Инструментальные средства разработки программ (ISRP 3301).pdf`
(97 страниц). Это силлабус в формате ЕНУ («Учебно-методический комплекс
дисциплины»): не просто список тем, а полноценный документ с уже готовым
конспектом лекций внутри. Отдельного учебника пока нет — этот файл и есть
основной источник по курсу, пока не появится что-то ещё.

Документ на английском (машинный перевод с русского, местами кривой
порядок слов — не путать с ошибкой распознавания).

## Смещение страниц — ВАЖНО, тут две разные пагинации

Файл состоит из двух разных документов, склеенных в один PDF, и у каждого
своя нумерация:

1. Страницы PDF 1-57 — сам силлабус (оргданные + готовый конспект по всем
   15 лекциям). Видимых номеров страниц в конспекте лекций нет — поэтому
   ниже даны прямые номера страниц PDF-файла, без пересчёта.
2. Страницы PDF 58-97 (примерно) — отдельная методичка «METHODICAL
   INSTRUCTIONS FOR PERFORMING LABORATORY WORKS», у неё СВОЯ внутренняя
   нумерация страниц, которая начинается заново с 1 (титул методички).
   Правило: страница PDF = внутренняя страница методички + 57.
   Проверено на CONTENTS методички (внутренняя стр. 3 = PDF 60).

Перед тем как открывать незнакомый раздел — свериться с заголовком на
первой странице диапазона.

## Часть 1. Конспект лекций (PDF-страницы 12-57)

Оргданные и формальности силлабуса — на PDF-страницах 1-11 (описание
курса, пререквизиты, тематический план по неделям, литература, критерии
оценивания). Собственно конспект лекций начинается на странице 12.

- Лекция 1. Введение. Классификация ПО ПК. Классификация и особенности
  современных инструментальных средств — PDF 12-13
- Лекция 2. Основы моделирования бизнес-процессов. Жизненный цикл ПО.
  Модели жизненного цикла (каскадная, спиральная) — PDF 14-15
- Лекция 3. Общие требования к методологии и технологии. Этапы
  проектирования систем. Требования к содержанию документов (ТЗ,
  эскизный проект, технический проект, рабочий проект) — PDF 15-19
- Лекция 4-5. CASE-технология проектирования систем структурного и
  объектно-ориентированного типов. Практические рекомендации по
  освоению и внедрению CASE-средств, критерии выбора — PDF 19-22
- Лекция 6. Структурный подход к проектированию ПО. Методология
  функционального моделирования SADT. Модель AS-IS/TO-BE и
  функционально-стоимостной анализ — PDF 22-25
- Лекция 7. Методология функционального моделирования IDEF0. CASE-
  средство структурного типа BPwin (ICOM-стрелки, туннели) — PDF 25-28
- Лекция 8-9. Отображение логического и физического уровней модели в
  ERwin. CASE-средство структурного типа ERwin (сущности, атрибуты,
  ключи, нормализация, домены, индексы, триггеры) — PDF 28-35
- Лекция 10. Model Mart — система управления моделями для групповой
  разработки — PDF 35-37
- Лекция 11. Унифицированный язык моделирования UML. Ключевые элементы
  объектно-ориентированного подхода — PDF 37-38
- Лекция 12. Диаграммы UML. Описание требований в контексте модели
  прецедентов (use case) — PDF 38-41
- Лекция 13. Классы. Диаграмма классов. Моделирование взаимодействия
  между объектами (атрибуты, операции, ассоциации, агрегация,
  композиция, обобщение, диаграммы последовательности) — PDF 41-50
- Лекция 14-15. Применение диаграмм UML каждого типа для моделирования
  поведения систем (диаграммы деятельности, состояний, компонентов,
  размещения). Проектирование систем в среде UML — Rational Rose, ARIS,
  MS Office Visio — PDF 50-57

## Инструменты курса (важно для раздела «Проверка» в CLAUDE.md)

BPwin, ERwin, IBM Rational Rose, ARIS (Toolset / Easy Design), MS Office
Visio — все старые Windows-only десктопные CASE-программы 1990-2000х,
в этом окружении их нет и запустить нельзя. AppMaster — облачная no-code
платформа (веб), тоже не проверяется скриптом из терминала.

## Литература

Основная: Гамма/Хелм/Джонсон/Влиссидес — «Приёмы объектно-ориентированного
проектирования» (Design Patterns, GoF); Вейцман — «Проектирование
информационных систем»; Белов — «Проектирование информационных систем»;
Брусникин/Соколова — «Разработка UML-моделей при проектировании
информационных систем».

Дополнительная: Грекул и др. — «Проектирование информационных систем»;
Шевчук — «Интеллектуальные информационные системы»; Цуканова —
«Методология и инструментарий моделирования бизнес-процессов».
